# Mnemon 记忆系统其余配置项核对

## 背景与关联
延续已有文档 `cb6bd015-c45f-4de5-9dc2-7aba240248a2`（存储范围 vs 记忆空间范围、三空间方案与路由原则）。用户（通信工程研究生，涉及课题组项目与课程）继续询问其余配置截图如何设置。本记录固化源码 / locale 文案核对结论与该用户的最终配置建议；均属推荐方案，用户未明确确认已实际应用。

## 项目档案范围（documentsScope）
- 两个选项（config locale `config.documentsScope*`）：
  - 「与 MEMORY.md 保存在同一存储根目录」= 默认，跟随存储范围 → 按工作区隔离。
  - 「所有工作区共用全局项目档案库」= 一套档案库所有工作区共用。
- 项目档案是三层记忆第二层，存整篇结构化长材料：实验方案、技术调研、论文大纲、课程笔记、项目流程与交接。与记忆空间（一条条事实/决策/关系）和运行时记忆（短约定）分工不同。记忆空间记"结论"，项目档案存"过程文档"。
- **建议保持默认（按工作区隔离）**：不同课题/课程的档案混进全局库检索噪音大；这与"记忆空间范围设 global 让个人事实跨项目共享"的目的相反——档案应跟项目走。
- 三个"范围"旋钮最终状态：存储范围=按工作区隔离（不动）；记忆空间范围=global（改）；项目档案范围=默认（不动）。

## 项目档案如何产生（无需预建"库"）
- 与记忆空间机制不同：记忆空间必须先手动创建/激活才存在；项目档案没有"先建库"这一步。
- 三条途径：
  1. 自动（主要）：分层策略 manifest 声明 `workflows: ['idle-review', ...]`，空闲复盘由任务 Agent 整理值得沉淀的设计/调查/流程类内容并自动创建，且跳过已有覆盖内容；用户无需操作。
  2. 手动：记忆系统 → 项目档案页手动新建单篇（标题 + 内容）。
  3. 对话中：让 Agent "把这段整理成档案存起来"。
- 写入范围以会话工作区（`agent.session.header.cwd`）为准；shell `cd`、来源文件路径、委派任务初始命令目录都不重新绑定会话工作区（documents README）。要给项目 B 建档案，需在 B 的工作区开会话，或在记忆系统里选中 B 手动建。
- Source `manage` / `create` action：`create` 仅新建独立档案，容量不足时失败而非更新/归档已有档案。

## 用户画像范围（runtimeUserScope）
- 两个选项（locale `config.runtimeUserScope*`、`storage.userProfileByWorkspace` / `storage.userProfileShared`）：
  - 「跟随存储范围」= 默认，USER.md 与 MEMORY.md 同目录。
  - 「全局共享」= 所有工作区共用一个用户画像，MEMORY.md 仍按存储范围隔离。
- **建议改成全局共享**：USER.md 存"你是谁"（通信工程研究生等），跨工作区都应被想起；与记忆空间设 global 同思路。
- 图 1 其余项（子 Agent 继承 Runtime 记忆、低优先级按需读取、工作记忆按需检索实验、推送索引实验、容量上限 4KiB/10KiB）保持默认/关。

## 主动记录（auto-capture）的"记录目标"勾选框
- 源码 `dsh-mnemon-strategy-auto-capture/lib/index.js`：`sourceKeys` 未配置时 = 所有 `durable-evidence` 角色来源（即记忆空间）；勾"记录目标"后出现来源列表供手动挑选。
- 挑选的是来源（Source）级别，不是单个空间名；尚无记忆空间时列表为空、勾选无反应属正常（曾据此纠正"未勾=自动全覆盖、勾上手动指定"的早期错误说法）。
- **建议保持未勾**：3 个空间建好后自动全部纳入记录范围，无需手动维护。该策略"引导当前 LLM 保留持久用户事实，不启动后台 Agent"。
- 图 2 其余（插件开关保持开、记录指引默认英文提示词、操作 ID `remember`）保持现状。

## 技能管理两个开关
- 允许更新链接技能（`allowLinkedUpdates`）：官方提示"更新将直接写回符号链接目标并影响共享 Agent，仅对可信目录启用" → **保持关**（会写穿共享技能文件）。
- 自进化（`evolution`）：后台复盘对话提技能建议；默认只建议、不自动采纳（草案需与当前版本回测后由用户手动采纳），不会偷偷改坏技能。缺点：每轮对话后额外 token/算力开销（任务 Agent 复盘+起草+回测）；本地留存复盘读过的对话（机密已替换）；持续积压待处理建议需打理。与"记住事实"目标无关 → **建议先关**。
- 图 3 其余（模型选择、草案 token、市场来源、技能目录）全部默认。

## 最终配置（供复核）
| 设置项 | 值 |
|---|---|
| 存储范围 | 集中存储·按工作区隔离（不动） |
| 记忆空间范围 | global 所有工作区共用（改） |
| 项目档案范围 | 跟随存储范围/默认（不动） |
| 用户画像范围 | 全局共享（改） |
| 三个记忆空间 | 个人与通用 / 课题组科研 / 课程学习，Mnemon Native，建后激活（见关联文档 cb6bd015） |
| auto-capture | 插件开、记录目标未勾、其余默认 |
| 技能管理 | 允许更新链接技能=关、自进化=关、其余默认 |

核心只改两个"范围"下拉（记忆空间范围 + 用户画像范围 → 全局共享）并建 3 个空间；项目档案无需预建库、按工作区隔离即可。
